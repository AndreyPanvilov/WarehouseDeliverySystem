# WarehouseDeliverySystem

Система симуляции складской логистики и доставки заказов на Python.

## Описание

Проект моделирует работу склада и курьерской службы: пользователи оформляют заказы, склад проверяет наличие товара и пополняет запасы у поставщика, пикеры комплектуют заказы, а курьеры доставляют их пользователям с учётом расстояния и времени в пути.

Основные сущности:
- `User` — пользователь с адресом доставки
- `Supplier` — поставщик товаров
- `Item` — товар
- `Warehouse` — склад с остатками, графиком работы и персоналом
- `Order` — заказ пользователя (статус: placed → picking → delivery → delivered)
- `Employee` / `Picker` / `Courier` — сотрудники со сменами и расчётом оплаты

## Требования

- Python 3.9+
- Только стандартная библиотека (`random`, `math`, `time`, `datetime`, `threading`, `queue`)

## Запуск

Одномодульная версия:

```bash
python main.py
```

Модульная версия:

```bash
python delivery_system.py
```

## Пример работы

При запуске создаются склад, поставщик, товары, пользователи, пикеры и курьеры. Склад оформляет заказ у поставщика, получает товары, после чего пользователи создают заказы. Заказы комплектуются пикерами и доставляются курьерами с выводом статусов и времени доставки.
